# Защита от потери файлов

## 🛡️ Система целостности проекта

Проект включает автоматизированную систему защиты от потери файлов и восстановления структуры.

## 📋 Проверка целостности

### Автоматическая проверка

```bash
npm run check
```

Эта команда проверяет:
- Наличие всех необходимых директорий
- Наличие всех необходимых файлов
- Размер каждого файла (для обнаружения пустых файлов)

### Что проверяется

**Директории:**
- `src/` - исходный код
- `src/game/` - игровая логика
- `src/game/events/` - события по расам
- `src/hooks/` - React хуки
- `src/components/` - React компоненты

**Файлы:**
- Основные файлы приложения (App.tsx, main.tsx, index.css)
- Игровая логика (types.ts, config.ts, data.ts, utils.ts)
- Система валидации (validation.ts)
- Система достижений (achievements.ts)
- Микро-события (microEvents.ts)
- Система наследия (legacy.ts)
- Система сохранений (saveSystem.ts)
- Аудио система (audio.ts)
- События для всех 6 рас
- Хук управления состоянием (useGameState.ts)
- Компонент управления аудио (AudioController.tsx)

## 🔧 Восстановление структуры

### Автоматическое восстановление

```bash
npm run restore
```

Эта команда:
- Создаёт отсутствующие директории
- Восстанавливает отсутствующие файлы из шаблонов
- Сохраняет существующие файлы без изменений

### Когда использовать

Используйте восстановление, если:
- Проверка целостности обнаружила отсутствующие файлы
- Проект не компилируется из-заmissing файлов
- Вы случайно удалили важные файлы

## 🚨 Предотвращение потери файлов

### Рекомендации

1. **Регулярная проверка**
   ```bash
   npm run check
   ```
   Запускайте перед каждым коммитом

2. **Git версии**
   - Коммитьте изменения регулярно
   - Используйте осмысленные сообщения коммитов
   - Создавайте теги для важных версий

3. **Backup**
   - Делайте резервные копии проекта
   - Используйте облачное хранилище
   - Храните несколько версий

4. **Документация**
   - Читайте ARCHITECTURE.md для понимания структуры
   - Следуйте стандартам кодирования
   - Документируйте изменения

### Автоматизация

Добавьте в `.git/hooks/pre-commit`:

```bash
#!/bin/bash
npm run check
if [ $? -ne 0 ]; then
  echo "❌ Проверка целостности не пройдена!"
  echo "Запустите 'npm run restore' для восстановления"
  exit 1
fi
```

## 📝 Логи и отладка

### Проверка конкретных файлов

```bash
# Проверить наличие файла
ls -la src/game/types.ts

# Проверить размер файла
wc -l src/game/types.ts

# Проверить содержимое
head -20 src/game/types.ts
```

### Отладка сборки

```bash
# Очистить кэш
rm -rf node_modules/.vite
rm -rf dist

# Пересобрать
npm run build

# Проверить ошибки
npm run build 2>&1 | grep -i error
```

## 🔒 Безопасность

### Защита от случайного удаления

1. **Git ignore**
   ```
   # .gitignore
   node_modules/
   dist/
   *.log
   .DS_Store
   ```

2. **Read-only файлы**
   ```bash
   # Сделать важные файлы read-only
   chmod 444 src/game/types.ts
   ```

3. **Backup перед изменениями**
   ```bash
   # Создать backup перед крупными изменениями
   cp -r src src.backup
   ```
