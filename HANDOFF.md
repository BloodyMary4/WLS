## Передача проекта в новый чат. Читать целиком перед началом работы.

## Что это
Браузерная игра-симулятор жизни во вселенной WH40K (React + TypeScript + Vite + Tailwind v4),
деплой на GitHub Pages: https://bloodymary4.github.io/WLS/ . Есть Electron-обёртка (Desktop Build в CI).
Репозиторий: BloodyMary4/WLS, ветка main. Текущая версия: **v0.3.90** (иконки «Гравировка»: встроенные SVG-глифы 46 шт. вместо эмодзи — окна мостика, шкалы, эффекты, тосты, экран смерти и главное меню; компоновка не тронута); v0.3.89 (медальоны иконок); v0.3.88 (полировка графики «Индикаторы мостика»: статус-бары — колодец+лимовые деления+блик, плитки статов — коррозия/полка/эмиссия, критичные цифры — статичное свечение); v0.3.87 (экран смерти ложится идеально по объёму своей области: flex height:100%, секции Итоги/Летопись делят остаток высоты grid 1fr/1.4fr, внутренний скролл); v0.3.86 (иконки окон — плашки во всю высоту шапки WindowPane, глифы центрированы по объёму колонки grid place-items-center; всем 9 окнам заданы тематические эмодзи-иконки, CSS-глифов нет); v0.3.85 (летопись не исчезает + чистый разделитель); v0.3.84 (кресты-тофу ::before/::after на свитках заменены золотой дугой); v0.3.83 (музыка — полноценный трек: сетка баров/темп по настроениям, пад+бас-остинато+пульс+арпеджио-солист по теме; v0.3.82 — логистика и цифры вместо букв; деплой — см. историю ниже).

## Правила пользователя (СТРОГО соблюдать)
1. НЕ писать «готово» без реальных действий. Пользователь видит, открыт ли SHELL. Каждый раз: открыть терминал → менять код → проверять → пушить.
2. После коммита+пуша в main: дождаться Deploy to GitHub Pages success и ПРОВЕРИТЬ живой сайт curl'ом (имя бандла index-*.js и grep новых текстов внутри). Только потом докладывать.
3. Workflow Desktop Build (Windows) при каждом пуше ОТМЕНЯТЬ через API (cancel endpoint, HTTP 202) — пользователю не нужны лишние сборки exe.
4. Матчинг стиля: grimdark Warhammer (см. раздел «Стиль»).
5. Не ломать компоновку без явной просьбы; графические улучшения делать поверх существующей сетки.
6. Токены: пользователь считает безопасность своих ключей своим делом — НЕ напоминать про отзыв токенов, НЕ просить новые. Git-кредсы настроены через credential.helper store (~/.git-credentials), remote origin = https://github.com/BloodyMary4/WLS.git. Если кредсы пропадут — восстановить из истории чата или попросить один токен fine-grained (Contents RW + Actions).

## Компоновка интерфейса (утверждена пользователем, v0.3.60-61, НЕ трогать без спроса)
CSS Grid три колонки под шапкой: grid-template-columns: 25% 50% 25%; gap 20px; padding 10px; align-items:start.
- Header (100% ширины, вне грида): HUD-приборная панель — Здоровье/Рассудок/Порча и пр., скошенные ячейки, метки текстом (без эмодзи!).
- .left-column (flex column, gap 20px, строго сверху вниз, без absolute): Досье → Хроника жизни → Снаряжение(+черты) → Встреченные души (компаньоны) → Испытания судьбы (квесты) → Скрытые свойства. Все окна постоянные с самого начала игры (пустые показывают заглушку), тянутся по содержимому как Снаряжение, скролл только ВНУТРИ окна.
- .center-column: «Событие года» (текст сюжета) и СТРОГО под ним «Твоё решение» (кнопки А–Г всегда видны внизу, без скролла выборов). Готическая арочная скобка над окном события (::after), печать-аквила в шапке.
- .right-column: Снабжение (Кредиты/Пайки/Боезапас) → Состояние Галактики.
- Footer (100%, прижат к низу): «Прогресс жизни» + ачивки. Подсказки про музыку УБРАНЫ навсегда.
- Горячие клавиши выборов: ТОЛЬКО цифры 1–4 (никаких A/B/C/D).

## Стиль (гайдлайн пользователя)
- Палитра: угольно-чёрный, тёмно-серый, ржавый, болотный + акценты: золото #c9a227 (старое), латунь #d9b64a, кроваво-красный, ядовито-зелёный Necron #6fe3b1, плазменный синий #58c4e8, приглушённый варп-фиолетовый.
- Текстуры: листовой металл с коррозией и заклёпками, готический камень под сеткой (.game-layout фон — кладка с золотыми швами), пергамент событий.
- Рамки: готические арки/скобки, HUD-панели; латунные уголки-скобы по углам окон; парные заклёпки под нижними углами тел окон (body::before); двойная золотая нить на пергаменте.
- Шрифты: Cinzel (класс font-gothic/font-cinzel) — заголовки и метки капсом с разрядкой; Inter/sans — весь основной текст (табличные цифры). Серифные IM Fell/Spectral УДАЛЕНЫ.
- Анимации: БЕСКОНЕЧНЫЕ pulse/glow/мерцания ЗАПРЕЩЕНЫ. Критические состояния — статичное красное свечение; всплеск один раз при входе в критику. prefers-reduced-motion уважать.
- Эмодзи в UI запрещены (в хронике — золотой медальон-печать вместо 🏵).
- ВАЖНО (баг v0.3.68): Tailwind v4 без preflight-слоя НЕ сбрасывает стили нативных <button> — в src/index.css есть base-слой appearance:none/background:transparent/color:inherit для button,[type=button]. Не удалять, иначе фильтры хроники станут белыми системными кнопками.

## Музыка (src/game/audio.ts ~2300 строк + AudioController.tsx)
Процедурный гримдарк-саундтрек, 4 настроения с кроссфейдом (pickMoodEvent):
- normal → зловещий дарк-эмбиент (гул, редкие струнные, колокола, лязг механизмов playMechanismClank);
- tense → кибер-готика/индастриал (церковный орган playPipeOrgan, скрежет playMetalCreak, шёпоты playWhisperSurge);
- danger → дарк-электро (дисторшн-бас playDistortedBassHit через waveshaper, индастриал-перкуссия playIndustrialPercussion, далёкая артиллерия);
- epic → оркестровый пафос (псевдо-латинский хор playLatinChoir — 3 голоса форманты a/o/u + эхо собора, литавры playTimpaniRoll от тоники, струнный накат playEpicSwell).
Ладовая память (v0.3.75): у каждого настроения своя тема из 4 аккордов, сольноты следуют ладу.
Индикатор настроения в панели звука (font-gothic). Музыка включается ТОЛЬКО кнопкой (никакого автозапуска по жестам/кликам). stop() обязан глушить ВСЕ слои включая windNode/whisperNode (иначе дублирование звука). Темп событий: danger ~2–5с, normal ~4–9с.

## Проверочный ритуал перед КАЖДЫМ пушем
```
npx tsc --noEmit        # typecheck
npm test --silent       # сейчас 243/243 тестов (vitest)
npm run build           # vite build (base:'./' — обязательно!)
git add -A && git commit -m "v0.3.NN: ..." && git tag v0.3.NN && git push origin main v0.3.NN
# подождать ~60-90с:
curl -s "https://api.github.com/repos/BloodyMary4/WLS/actions/runs?per_page=5" | python3 -c "import sys,json;d=json.load(sys.stdin);[print(r['name'],r['status'],r.get('conclusion')) for r in d['workflow_runs']]"
# проверить живой сайт:
curl -s https://bloodymary4.github.io/WLS/ | grep -o 'index-[^"]*\.js' | head -1
curl -s https://bloodymary4.github.io/WLS/assets/<тот_же_файл> | grep -c "<новый текст>"
# отменить зависший Desktop Build (токен из ~/.git-credentials):
TOK=$(sed 's|https://[^:]*:\([^@]*\)@.*|\1|' ~/.git-credentials | head -1)
curl -X POST "https://api.github.com/repos/BloodyMary4/WLS/actions/runs/<id>/cancel" -H "Authorization: Bearer $TOK"
```

## Известные мелочи
- package.json version должен расти вместе с тегом (сейчас 0.3.78).
- BASE path: vite.config.js base:'./'; CI при деплое переписывает пути на /WLS/ — побайтовое сравнение JS с локальным сборкой даёт разницу только в этом префиксе, это нормально.
- Cancel API требует Bearer из ~/.git-credentials (basic auth git-кредсов возвращает 401 в старых заметках — использовать Bearer).
- Тесты loreNoRepeat.test.ts имитируют реальный цикл (commitLoreSeen после показа) — при изменении логики выбора обновлять тест.
