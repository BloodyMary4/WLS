## 🤖 Автоматизация

### Git hooks

Добавьте в `.git/hooks/pre-commit`:

```bash
#!/bin/bash
npm run check
if [ $? -ne 0 ]; then
  echo "❌ Проверка целостности не пройдена!"
  echo "Запустите 'npm run restore' для восстановления"
  exit 1
fi
```

### CI/CD

Добавьте в ваш CI/CD pipeline:

```yaml
- name: Check project integrity
  run: npm run check

- name: Build project
  run: npm run build
```

### Pre-commit hook (npm)

Установите `husky` и `lint-staged`:

```bash
npm install -D husky lint-staged
npx husky install
npx husky add .husky/pre-commit "npm run check"
```
