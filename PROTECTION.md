### 2. Скрипты автоматизации

#### scripts/check-integrity.ts
**Команда**: `npm run check`

Проверяет:
- ✅ Наличие всех необходимых директорий
- ✅ Наличие всех необходимых файлов
- ✅ Размер каждого файла
- ✅ Выводит подробный отчёт

**Пример вывода:**
```
🔍 Проверка целостности проекта...

📁 Проверка директорий:
  ✅ src
  ✅ src/game
  ✅ src/game/events
  ✅ src/hooks
  ✅ src/components

📄 Проверка файлов:
  ✅ src/App.tsx (15.23 KB)
  ✅ src/game/types.ts (3.45 KB)
  ✅ src/game/data.ts (12.67 KB)
  ...

✅ Все файлы и директории на месте!
📊 Статистика:
   - Проверено файлов: 21
   - Проверено директорий: 5
   - Пропущено: 0
```

#### scripts/restore-structure.ts
**Команда**: `npm run restore`

Восстанавливает:
- ✅ Отсутствующие директории
- ✅ Отсутствующие файлы из шаблонов
- ✅ Сохраняет существующие файлы

**Пример вывода:**
```
🔧 Восстановление структуры проекта...

📁 Создание директорий:
  ✓ Существует: src
  ✓ Существует: src/game
  ✅ Создана: src/game/events
  ...

📄 Восстановление файлов:
  ✓ Существует: src/App.tsx
  ✅ Восстановлен: src/game/types.ts
  ...

✅ Восстановление завершено!
💡 Теперь запустите "npm run check" для проверки целостности
```

## 🚀 Как использовать

### Регулярная проверка

Перед каждым коммитом:
```bash
npm run check
```

### Восстановление после потери

Если файлы потеряны:
```bash
npm run restore
npm run check
```

### Автоматизация в Git

Добавьте в `.git/hooks/pre-commit`:
```bash
#!/bin/bash
npm run check
if [ $? -ne 0 ]; then
  echo "❌ Проверка целостности не пройдена!"
  echo "Запустите 'npm run restore' для восстановления"
  exit 1
fi
```
